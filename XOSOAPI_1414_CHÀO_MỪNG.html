Cache & bảo vệ API

Dữ liệu đã có trong Supabase sẽ được trả từ cache để giảm thời gian phản hồi và giảm số lần gọi nguồn ngoài.

API yêu cầu key hợp lệ và có giới hạn 60 request/phút cho mỗi key.

CHÀO MỪNG ĐẾN XOSOAPI

Nền tảng dữ liệu xổ số & API thông minh

XOSOAPI cung cấp dữ liệu kết quả xổ số ba miền, hỗ trợ lập trình viên, website và ứng dụng tích hợp API tự động.

📡 Cập nhật kết quả xổ số LIVE khi có dữ liệu 🗃️ Tra cứu và thống kê dữ liệu lịch sử 🔑 API Key riêng, quản lý hạn sử dụng 🔒 Bảo vệ tài khoản và quyền truy cập
ℹ️ Điều khoản sử dụng

Dữ liệu và công cụ phục vụ tra cứu, nghiên cứu, phát triển phần mềm và các mục đích hợp pháp.

XOSOAPI không tổ chức, môi giới hoặc hỗ trợ cá cược trái pháp luật. Người dùng tự chịu trách nhiệm tuân thủ pháp luật và kiểm tra dữ liệu trước khi sử dụng.

Kết quả LIVE phụ thuộc thời điểm và độ chính xác của nguồn cung cấp; dữ liệu có thể cập nhật trễ.

Xác nhận được ghi nhớ trên trình duyệt này. Khi điều khoản thay đổi, bạn sẽ cần xác nhận lại.
