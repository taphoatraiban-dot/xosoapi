Tài liệu API xổ số Việt Nam

Tra cứu kết quả miền Nam (MN), miền Trung (MT), miền Bắc (MB) theo ngày. Ví dụ bên dưới sử dụng endpoint đọc kết quả công khai, không phải endpoint thương mại yêu cầu API key.

1. Endpoint đọc kết quả công khai

GET https://zigpqddlhvjbjrwhfhaa.supabase.co/functions/v1/xoso-public?region=MN&date=2026-10-20
Tham sốGiá trị
regionMN, MT, MB
dateYYYY-MM-DD, mặc định ngày hiện tại theo Việt Nam

Ví dụ phản hồi (rút gọn)

{ "success": true, "region": "MN", "date": "2026-10-20", "source": "...", "count": 3, "data": [{ "province": "...", "prizes": { "db": ["..."], "g1": ["..."] } }] }

Trường data là danh sách đài; mỗi đài có province và prizes. Khi chưa có dữ liệu, phản hồi có thể chứa success: false và data: [].

2. Dùng thử ngay

Chọn miền và ngày rồi nhấn Gửi yêu cầu.

3. API key và giới hạn sử dụng

Đăng ký / đăng nhập để vào Dashboard. Tại đây bạn có thể xem API key, gói hiện tại, hạn sử dụng, tổng số request và số request trong ngày theo quyền tài khoản.

GóiGiới hạn trong hệ thống
Dùng thử500 request/ngày; 30 request/phút
Cơ bản2.000 request/ngày; 60 request/phút
Nâng cao5.000 request/ngày; 120 request/phút
Pro10.000 request/ngày; 300 request/phút

Lưu ý: API key và hạn mức tài khoản đã có trong Dashboard, nhưng endpoint thương mại xác thực API key chưa được xác nhận hoạt động đầu-cuối. Không nên coi endpoint công khai phía trên là dịch vụ API key có bảo đảm hạn mức hoặc SLA.

4. Thanh toán và gia hạn

Xem bảng giá và QR chuyển khoản. Sau khi chuyển khoản, gửi yêu cầu nâng cấp. Quản trị viên xác nhận thanh toán và kích hoạt/gia hạn thủ công; không tự động mở quyền chỉ vì người dùng nhấn nút đã thanh toán.

Trước khi kinh doanh API trả phí, cần xác minh quyền phân phối thương mại đối với dữ liệu nguồn.
