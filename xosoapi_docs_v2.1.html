Cache

Dữ liệu lưu ở lottery_results theo region + draw_date.

Nếu có sẵn dữ liệu, API trả thêm:

"cached": true

API key & giới hạn

API bắt buộc có:

&key=YOUR_API_KEY

Mỗi key giới hạn:

60 request / phút

Bảng đếm:

api_rate_limits
- api_key
- window_start
- request_count
Hiện tại hệ thống đang dùng một key chung từ Secret XOSO_API_KEY. Có thể nâng cấp thành nhiều key riêng cho từng khách hàng.
