4. Kết nối API hiện tại

Nhập API Key được cấp trên Dashboard. Key không được lưu vào bộ nhớ trình duyệt. API có thể chỉ trả kết quả hoàn chỉnh, không đảm bảo có dữ liệu từng giải theo thời gian thực.

Nhập API Key trên Dashboard rồi bấm “Lấy kết quả từ API”.

Kết quả lấy từ API được lưu riêng theo miền và ngày trên thiết bị này. Chỉ đối chiếu khi đã kiểm tra ngày và đài.
